## Attribution and source hygiene

- Verify commit attribution with `git show --format=fuller` before citing or
  cherry-picking. The table's short hashes identify candidate history, not a
  license grant for third-party artwork.
- Preserve GPLv3 and applicable third-party notices. Do not include EA game
  assets, unlicensed splash art, user game files, signing keys, or release
  secrets.
- Upstream PRs should state one narrow problem, implementation, tests and device
  status. Do not claim Android compatibility solely from a host JVM test.
- Re-run `git status` and compare against current upstream immediately before
  implementation; the two repositories continue to change.
