# Material Design icons

The launcher uses selected Material Icons from Google, including Home, Folder
Open, Settings, Touch App, Extension, Map, Analytics, Play Arrow, File Download,
Check Circle, Keyboard, List, Close, Arrow Back, and Open in New.
